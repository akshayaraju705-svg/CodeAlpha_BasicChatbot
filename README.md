# Basic Chatbot

## CodeAlpha Python Programming Internship

### Task 4 - Basic Chatbot

## Project Description

This project is a simple rule-based chatbot developed using Python. It interacts with the user through the command line and provides responses to common greetings and questions.

## Features

* Responds to greetings such as Hello and Hi
* Responds to "How are you?"
* Tells the chatbot's name
* Explains what the chatbot can do
* Responds to thank-you messages
* Allows the user to exit by typing "bye" or "exit"
* Provides a default response for unknown messages

## Technologies Used

* Python

## Concepts Used

* User Input
* Conditional Statements
* While Loop
* String Handling
* Variables
* Break Statement

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python chatbot.py
```

6. Enter messages in the terminal to interact with the chatbot.

## Sample Interaction

```text
Chatbot: Hello! I am your basic chatbot.
Chatbot: You can ask me simple questions.
Chatbot: Type 'bye' to exit.

You: hello
Chatbot: Hello! How are you?

You: what is your name
Chatbot: My name is CodeBot.

You: how are you
Chatbot: I am fine, thank you! How can I help you?

You: thank you
Chatbot: You're welcome!

You: bye
Chatbot: Goodbye! Have a nice day!
```
